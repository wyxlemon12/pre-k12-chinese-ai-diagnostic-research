B 方向细化：Studio First 老师工作台

这一版不是“系统首页”，而是老师一进来就进入工作状态的主屏。它借可汗老师后台的稳定秩序，但把真正最大的面积给 “当前微课包”。

主任务：生成并确认微课包
副任务：课堂运行 / 课后回写 / 学生记录
视觉气质：可信、明亮、平静、学术感轻运营
左侧导航

固定保留 5 个一级入口：微课包、课堂运行、课后反馈、学生记录、工具箱。位置稳定，像可汗老师后台。

中间主画布

永远显示“当前微课包”，这里是产品核心，不被各种统计卡和设置面板挤掉。

右侧老师助手

只放老师真正会用的东西：当前建议、支架切换、提醒卡。AI 不直接讲话，只做后台编排结果展示。

下方承接层

展示学生卡片、最近反馈、素材来源，让系统完整但不抢主任务注意力。

这一屏我想先确认的不是细节文案，而是结构判断：
  • 首页是否应该直接进入“当前微课包工作台”，而不是先看总览统计。
  • 右侧老师助手区是否值得长期固定存在，作为这个产品区别于普通后台的关键特征。
  • 下方承接层是否足够克制，没有把页面又做回传统管理后台。
