# 6岁中文课堂案例笔记

## 案例一：香港教育局《童心童趣》单元一《上学》教学设计

来源：
[香港教育局公开 PDF](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/resources/tongxin_content_page/tongxin_01_plans.pdf)

本地保存：
`reference/cases/香港教育局-童心童趣-单元一上学-教学设计.pdf`

### 关键观察

- 教学不是“读文 -> 做题”的单一流程，而是 `引入经验 -> 看图推测 -> 连续追问 -> 讨论/角色扮演 -> 工作纸`。
- 老师通过大量追问带动理解，说明系统必须支持 `提问梯度卡`。
- 课堂是高度互动的，说明产品不能要求老师持续盯设备。
- 这份案例非常适合支持“儿童体验”和“课堂节奏”设计，但不适合直接作为文本库样本，因为其核心绘本内容未完整公开。

### 对 PRD 的启发

- 必须支持微活动节奏。
- 必须支持无设备课堂包。
- 必须把观察点设计成高信息量的少量打点，而不是逐个学生重记录。

## 案例二：香港教育局小一《中国语文（非华语学生适用）》第七课《我的家》

来源：
[香港教育局公开 PDF](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/second-lang/pri_package_student/P1_Ch7_SB.pdf)

本地保存：
`reference/cases/香港教育局-小一-我的家-课册.pdf`

### 关键观察

- 任务链很完整：
  - 说一说
  - 学句子
  - 看图说话
  - 课文阅读
  - 考考你
  - 连一连
  - 学字词
- 很适合做结构化教学样本，因为可以从中抽取：
  - 目标词
  - 目标句
  - 目标理解点
  - 工作纸证据

### 对 PRD 的启发

- 适合作为首版样本课。
- 工作纸应进入诊断证据链。
- 对混合起点班级，系统应提供图片支持、句框、选图回应等低门槛支架。

## 综合结论

- 6 岁中文课堂的关键不是多长的文章，而是活动链路是否自然、回应方式是否低门槛、老师是否看得清卡点。
- 产品的核心价值应定义为：
  `帮助老师为不同起点的孩子选对文本入口、看清薄弱环节、设计下一步支架。`
